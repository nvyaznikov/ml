# 🌐 ML-Start Test Task - Портфолио Никита Вязников

## 📋 Описание проекта

Это тестовое задание для **ML-Start**

Одностраничный сайт-портфолио **HTML, CSS + JavaScript**

## 🚀 Функциональность

- **Header** с лого, меню и свитчем темы
- **Обо мне** — информация + адаптивное фото под разные у-ва (через picture и srcset)
- **Навыки** — карточки с иконками технологий (HTML, CSS, JS, React)
- **Портфолио** — карточки работ с описанием
- **Контакты** — кнопки для связи (Telegram, GitHub, Email)
- **Popup**, открывающееся по кнопке телефона
- **Footer**

## 💡 Используемые технологии

- **HTML5** 
- **CSS3** 
- **JavaScript**
- **Tabler Icons** — иконки для интерфейса
- **Montserrat** — шрифт проекта

## 🧭 Как работает сайт

1. При загрузке страницы отображается шапка с меню, блок обо мне и кнопкой вызова popup.
2. Кнопка телефона (справа внизу) открывает popup с контентом.
3. Свитч темы в шапке изменяет тему сайта.
4. Меню навигации осуществляет плавный скролл до соответствующих секций.
5. Изображения подгружаются адаптивно через `<picture>` и `srcset` для разных экранов.
